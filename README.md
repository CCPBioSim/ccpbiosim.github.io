# CCPBioSim Devs repo

[![software handler](https://github.com/CCPBioSim/ccpbiosim.github.io/actions/workflows/software.yaml/badge.svg)](https://github.com/CCPBioSim/ccpbiosim.github.io/actions/workflows/software.yaml)
[![workshops handler](https://github.com/CCPBioSim/ccpbiosim.github.io/actions/workflows/workshops.yaml/badge.svg)](https://github.com/CCPBioSim/ccpbiosim.github.io/actions/workflows/workshops.yaml)

This repo holds `assets.json`, which tracks the latest versions of CCPBioSim software and workshop containers. It is updated by the `software` and `workshops` workflows when a project makes a release.

The developer documentation has moved to the [CCPBioSim](https://github.com/CCPBioSim/CCPBioSim) repository and can be viewed [here](https://ccpbiosim.readthedocs.io/).
